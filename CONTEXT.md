# BeeBank

"фінтех для пасіки": банк, клієнтами якого є вулики. Демо-домен для доповіді про MCP.

## Language

**BeeBank**:
Банк, що обслуговує вулики пасіки.
_Avoid_: пасіка (як назва системи)

**Hive**:
Вулик — клієнт BeeBank. Має ім'я, матку (**Queen**) і статус (**Active** / **Frozen**).
_Avoid_: client, customer, user, account

**Queen**:
Матка вулика; лише ім'я, без власної поведінки.

**Frozen**:
Статус **Hive**, за якого вулик не може ні відправляти, ні отримувати **Honey**. Заміна видаленню для вуликів з історією.
_Avoid_: deleted, closed, blocked

**Honey**:
Валюта BeeBank. Обліковується цілими грамами (аналог minor units), без дробових значень.
_Avoid_: гроші, кошти, кг (як одиниця обліку; кг — лише для відображення)

**Ledger**:
Незмінний журнал усіх **Operations**. Записи ніколи не змінюються й не видаляються.

**Operation**:
Запис у **Ledger**, що змінює **Balance** одного або двох вуликів. Види: **Harvest**, **Withdrawal**, **Transfer**, **Interest**.

**Harvest**:
Надходження **Honey** у вулик ззовні (збір нектару).

**Withdrawal**:
Пасічник забирає **Honey** з вулика.
_Avoid_: списання, debit

**Transfer**:
Переміщення **Honey** від одного **Hive** до іншого з обов'язковим **Memo**.

**Memo**:
Довільний текст від відправника **Transfer**: призначення переказу.

**Interest**:
"Медові відсотки" — надходження **Honey**, нараховане банком усім вуликам пропорційно балансу.

**Balance**:
Кількість **Honey** (у грамах), що належить **Hive**. Завжди обчислюється з **Ledger**, ніколи не зберігається.

## Relationships

- **Hive** має рівно один **Balance**
- **Balance** = сума всіх **Operations** вулика в **Ledger**
- **Transfer** зачіпає два різні **Hive**; решта **Operations** — один

## Rules

- **Balance** не може стати від'ємним (без овердрафту)
- **Frozen** вулик не бере участі в жодній **Operation**
- Сума будь-якої **Operation** > 0
- **Transfer** самому собі заборонено
- **Hive** можна видалити лише якщо в нього немає **Operations**; інакше — лише **Frozen**
